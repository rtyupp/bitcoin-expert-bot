# بوت خبير وتداول البيتكوين المؤسسي المتكيف (Bitcoin Institutional Trader)

نظام متكامل لتداول البيتكوين (`BTCUSD`) يدمج بين **بيانات Capital.com المباشرة** و **تيليجرام** مع نظام تكيفي شامل يتأقلم مع جميع ظروف السوق.

---

## 🎯 الاستراتيجيات الأربع المتكيفة (Multi-Regime Portfolio)

1. **[B] سحابة إيشيموكو وبولينجر 4H (Jesse Ichimoku Cloud Breakout):**
   - **الهدف:** ركوب موجات الاتجاه المؤسسي العنيفة.
   - **الأداء التاريخي (2018 - 2026):** معامل ربح **`PF 2.03`**، عائد تراكمي **`+490%`**.
2. **[C] قنص كنس السيولة 4H (SMC Liquidity Sweep):**
   - **الهدف:** اصطياد فخاخ الدببة وصناع السوق عند كسر قاع 24 شمعة ثم الارتداد.
   - **الأداء التاريخي:** معامل ربح **`PF 1.73`**، نسبة فوز **`46.4%`** بهدف 1:2.
3. **[A] اختراق دونشيان اليومي 55 (Donchian 55 Daily):**
   - **الهدف:** اقتناص انطلاقات الدورات السعرية الكبرى بعد كسر قمة 55 يوماً.
   - **الأداء التاريخي:** معامل ربح **`PF 1.92`**، نسبة فوز **`49.0%`**.
4. **[D] اختراق الزخم السريع 1H (Fast Donchian 20):**
   - **الهدف:** صفقات سريعة ومستمرة (صفقة كل يوم إلى يومين) مع تأكيد الاتجاه والفوليوم.
   - **الأداء التاريخي:** صافي ربح **`+184.0 R`**.

## ⚡ الميزات التقنية
- **إدارة الجلسات في كابيتال (Session Caching):** منع خطأ 429 والحفاظ على استقرار الاتصال.
- **إدارة المخاطر الصارمة:** حساب حجم اللوت تلقائياً بحيث لا تتجاوز الخسارة 1% من الرصيد.
- **تأمين الوقف التلقائي (Break-Even):** تحريك الوقف إلى نقطة الدخول عند وصول السعر إلى `+1.0R`.
- **معنويات المتداولين (Sentiment Indicator):** قراءة حية لنسبة المشترين والبائعين على المنصة.
- **شارت شموع يابانية مباشر:** توليد شارت عالي الدقة يوضح المتوسطات ونقاط الدخول.
