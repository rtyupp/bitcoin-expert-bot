# 🪙 بوت خبير البيتكوين المؤسسي (Bitcoin Institutional Elite Trading Bot)

مشروع متخصص بالكامل في **البيتكوين (BTC)** بنظام توصيات وتداول آلي قائم على **3 من أقوى استراتيجيات المحترفين عالمياً** المثبتة إحصائياً ومجربة على 8 سنوات (2018 - 2026) من البيانات الحقيقية بعد خصم تكاليف السبريد والانزلاق ورسوم التبييت، مع ربط كامل مع منصة **Capital.com** وبوت تيليجرام تفاعلي.

---

### 🎯 الاستراتيجيات المعتمدة ونتائج الاختبار التاريخي (2018 - 2026)

| الاستراتيجية | الفريم | النمط | نسبة الفوز | عامل الربح (PF) | صافي الأرباح | التردد |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| **A) اختراق دونشيان اليومي** | 1D | سوينغ موجي كاسح | **61.1%** | **2.41** | **+23.6R** | ~4 صفقات/سنة |
| **C) قنص السيولة المؤسسية** | 4H | فخاخ الدببة (SMC Sweep) | **52.4%** | **1.87** | **+19.2R** | ~5 صفقات/سنة |
| **B) نظام السلاحف 4H (Turtle 20)** | 4H | كسر 20 شمعة + وقف متحرك | **33.9%** | **1.31** | **+71.8R** | **~1 صفقة/أسبوع** |
| **المحفظة مجتمعة (Portfolio)** | - | **3 استراتيجيات بخانات مستقلة** | **37.6%** | **1.42** | **+114.5R** | **~54 صفقة/سنة (~1.0/أسبوع)** |

> **ملاحظة:** النتائج تشمل خصم تكلفة السبريد والانزلاق (0.12%) ورسوم التبييت اليومية (0.06%). وفي اختبار **خارج العينة (2024 - 2026)** حققت المحفظة عامل ربح **1.20** و **+19.4R**.

### 🚀 الميزات الرئيسية

1. **نظام فحص آلي للشموع المكتملة:**
   - فحص دوري كل دقيقة للشموع المكتملة لمنع أي إعادة رسم (No Repainting).
   - إرسال إشعار فوري على تيليجرام مع رسم الشارت البياني ومستويات الدخول/الهدف/الوقف.

2. **تكامل كامل مع Capital.com Demo API:**
   - فتح صفقات الشراء والبيع تلقائياً بحجم محسوب بدقة حسب نسبة المخاطرة المحددة من المحفظة.
   - متابعة الصفقات المفتوحة وإغلاقها فور تحقق الهدف أو ضرب الوقف أو تحريك الوقف المتحرك.

3. **لوحة تحكم تيليجرام تفاعلية:**
   - 🪙 **حالة البيتكوين:** فحص مباشر لنظام السوق، قمم وقيعان الـ 20 شمعة، والمؤشرات.
   - 🕯️ **الشارت:** رسم بياني عالي الدقة يوضح الشموع والمتوسطات والصفقات.
   - 🎯 **الصفقات النشطة:** استعراض الصفقات المفتوحة وربحيتها بالـ R.
   - 💼 **حساب كابيتال:** تفاصيل الرصيد، الهامش، والأرباح العائمة.
   - ⚙️ **إعدادات التداول:** تفعيل/تعطيل التداول الآلي، وضبط نسبة المخاطرة.
   - 🟢/🔴 **تداول فوري:** أوامر شراء وبيع يدوية بضغطة زر.

### 🛠 تشغيل وتثبيت المشروع

#### 1. التشغيل المحلي:
```bash
# تثبيت الحزم
pip install -r requirements.txt

# تشغيل الفحص الذاتي للتأكد من سلامة النظام
python selftest.py

# تشغيل البوت
python bot.py
```

#### 2. المتغيرات البيئية المطلوبة (.env):
```env
BOT_TOKEN=your_telegram_bot_token
DAILY_CHAT_ID=your_chat_id
CAPITAL_EMAIL=your_capital_email
CAPITAL_API_KEY=your_capital_api_key
CAPITAL_API_PASSWORD=your_capital_api_password
CAPITAL_AUTO_TRADE=1
RISK_PCT=1.0
```

#### 3. الاستضافة المجانية 24/7:
يعمل البوت تلقائياً ومجاناً عبر **GitHub Actions** على مدار الساعة دون الحاجة لأي بطاقة ائتمان.
