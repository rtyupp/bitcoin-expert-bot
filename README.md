## 🛡️ قواعد إدارة المخاطر وتأمين الصفقات
1. **قاعدة عدم التكرار (Single Position per Asset):** لا يتم فتح أكثر من صفقة واحدة لنفس الأصل في نفس الوقت لمنع تراكم المخاطر.
2. **تأمين الدخول (Break-Even):** عند وصول الربح العائم إلى `+1.0 R` على الشمعة المغلقة، يتم نقل الوقف تلقائياً عبر API المنصة إلى سعر الدخول.
3. **الخروج الذكي (Smart Exit):** خروج Chandelier بمقدار 4×ATR لـ GBP/USD و 2×ATR للمعادن.
4. **حجم العقد التكيفي:** حساب دقيق لحجم العقد بناءً على نسبة المخاطرة المحددة (مثلاً 1.0% من الرصيد المتاح).
